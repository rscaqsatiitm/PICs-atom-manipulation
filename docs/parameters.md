## Result files

- `results/m1_bend_loss.json`: Values below ~1e-6 dB/90 are at the numerical floor. Mode-mismatch loss at straight-bend junctions is not included.
- `results/m1_box_leakage.json`: Values below ~1e-5 dB/cm are at the numerical floor.
- `results/m1_coupling.json`: Power transfer over a parallel length L is sin^2(pi L / (2 L_c)); crosstalk below -30 dB needs L < 0.02 L_c.

- `results/m2_couplers.json`: Excludes Fresnel loss (index-matched or AR-coated facet assumed) and taper conversion loss.
- `results/m2_mmi.json`: 2D effective-index model; excess loss from unguided content only (no sidewall scattering, no back-reflection). Absolute loss should be confirmed by 3D EME/FDTD.
- `results/m3_field_tradeoff.json`: 1D scalar Fourier optics; aplanatic objective (pupil radius F NA). The number of resolvable positions equals N; the range at the atoms is N lambda/(4 NA fill).
- `results/m3_grating.json`: 2D model of a uniform grating. Directionality oscillates with buried-oxide thickness through the Si-substrate reflection; a bottom reflector or a two-layer grating is needed for > 0.8.
- `results/m3_loss_budget.json`: Per-tweezer share of the emitted power for K = 21 at N = 128, 2 um pitch. The 6.6 mW per tweezer target uses the proposal's w0 = 1.04 um; the OPA spot differs (see m3_spot).
- `results/m3_multibeam.json`: One row of the lattice along the steering axis. K is limited by the number of sites in range.
- `results/m3_noise.json`: Static (frozen) channel errors. For a time-varying error the same mapping gives the position noise spectrum, which sets heating (see m7_budget).
